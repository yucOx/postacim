2 · Sunucu neyi görür, neyi göremez

👁️ Görebilir (metadata)

  • nick · hesap tarihi · son aktivite
  • sosyal graf: kim ↔ kim, arkadaş, DM, üyelik, rol
  • mesaj zamanı, boyut bucket'ı (padding sonrası), epoch
  • topluluk/kanal/grup adları, avatar (bilerek açık)
  • session hash'i, arama katılımı, WS presence

🔒 Göremez (kripto)

  • mesaj/DM/grup içeriği — XChaCha20-Poly1305
  • şifre · KEK · özel anahtar · kurtarma ifadesi
  • kanal anahtarlarının açık hali
  • ses/görüntü içeriği (SFrame)
  • okundu bilgisi (cihaz dışına çıkmaz)

3 · Bir mesajın yolculuğu

1 · Türethash-ratchet: zincir index'i → msg_key
2 · Doldurgövde + header → 4 KB bucket'a yuvarlanır
3 · ŞifreleXChaCha20-Poly1305
AAD: scope:kanal:epoch:i:clientId
4 · Relaysunucu saklar + WS broadcast (içerik göremez)
5 · Çözalıcı aynı zincirden key türetir
6 · Hataepoch eksik → DecryptError

4 · Silme · talepler · sınırlar

🗑️ Silmeherkes için: gönderen tombstone, nonce+ciphertext NULL · benim için: localStorage · hesap silme: kimlik+mesajlar+DM'ler+gruplar, tek transaction, geri alınamaz
⚖️ Hukuki talepverilebilir: nick, argon2 verifier, zaman damgaları, loglar · verilemez: içerik — çözme anahtarı hiçbir koşulda elimizde değil
⚠️ Web sınırıistemci JS'i sunucudan dağıtılır — operatör değiştirilmiş kod servise edebilir (her web E2EE'nin sınırı). Savunma katmanları: güvenlik numarası + TOFU pinning + anahtar defteri (append-only zincir; head damgası iki cihaz arasında bant dışı karşılaştırılınca view-splitting yakalanır)
